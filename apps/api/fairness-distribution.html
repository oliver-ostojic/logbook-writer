How to read the Lorenz Curve:

The diagonal dashed line represents perfect equality (everyone gets equal minutes).

The red area between the curve and the diagonal represents inequality - larger area = more unequal.

Gini coefficient = 2 × (area between curve and diagonal). Range: 0 (perfect equality) to 1 (maximum inequality).
